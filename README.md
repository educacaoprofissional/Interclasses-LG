# INTERCLASSES LG

Portal web do projeto **INTERCLASSES LG**, desenvolvido para organizar e apresentar informações dos torneios interclasses da escola, incluindo modalidades, regras, equipes, programação e conteúdo motivacional.

## Tecnologias

- React 18
- TypeScript
- Vite
- Tailwind CSS 4
- Motion
- Lucide React

## Executar no GitHub Codespaces

1. Crie o repositório da equipe e envie **o conteúdo desta pasta para a raiz**.
2. No repositório: **Code > Codespaces > Create codespace on main**.
3. Aguarde o Codespaces concluir a configuração.
4. Execute:

```bash
npm start
```

5. Abra **PORTS > 5173 > Open in Browser**.

## Instalação manual

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

A configuração `base: './'` do Vite deixa o build mais adequado para futura publicação em GitHub Pages.
